Remarks

Reuses the caller's HeaderName header when present, otherwise generates a new GUID. The ID is stored in CorrelationIdAccessor, echoed back on the response header, and pushed as a CorrelationId logging scope for the rest of the pipeline. Register it (via UseCorrelationIdMiddleware()) before UseExceptionHandler() so exception responses can include the ID.

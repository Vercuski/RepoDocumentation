Remarks

Every project in the solution is versioned from the same git tags, so all assemblies carry the same version. Current therefore reads this (Infrastructure) assembly rather than GetEntryAssembly(), which is the test host under WebApplicationFactory and would report the wrong version. Registered as a singleton by AddInfrastructureRegistration().

ToActionResult<T, TResponse>(Result<T>, ControllerBase, Func<T, TResponse>)

Maps a Result<T> to an IActionResult, projecting the success value through onSuccess (e.g. entity -> DTO) before returning it via 200 OK. Mirrors the original controller behavior of treating a success with a null value as not-found.

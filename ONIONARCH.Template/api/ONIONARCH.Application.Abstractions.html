Interfaces

IAppRequest<TResponse>

Base marker for anything dispatchable through ISender. Deliberately carries no members — it exists purely so Send<TResponse>(IAppRequest<TResponse>, CancellationToken) and IPipelineBehavior<TRequest, TResponse> have a single covariant type to close their generics over, regardless of whether the concrete request is a query or a command.

ICommandHandler<TCommand, TResponse>

Handles a state-changing ICommandRequest<TResponse>.

ICommandRequest<TResponse>

Marker for a CQRS command — a request that changes system state. Handled by an ICommandHandler<TCommand, TResponse>.

IDomainMapper<TEntity>

Implemented by inbound DTOs that know how to convert themselves into a domain entity.

IPipelineBehavior<TRequest, TResponse>

Cross-cutting wrapper around a request/handler pair, resolved and chained by ONIONARCH.Application.Sender for every dispatched request regardless of its concrete type. Mirrors MediatR's IPipelineBehavior<TRequest,TResponse> shape closely enough that behaviors written for it (see LoggingBehavior<TRequest, TResponse>) only need their next delegate signature updated.

IQueryHandler<TQuery, TResponse>

Handles a read-only IQueryRequest<TResponse>.

IQueryRequest<TResponse>

Marker for a CQRS query — a request that reads data without changing system state. Handled by an IQueryHandler<TQuery, TResponse>.

IRequestHandler<TRequest, TResponse>

Base handler contract. ONIONARCH.Application.Sender always resolves the closed generic IRequestHandler<TRequest, TResponse> for the request's runtime type — it never needs to know whether the concrete request is a query or a command. IQueryHandler<TQuery, TResponse> and ICommandHandler<TCommand, TResponse> exist purely as semantic/namespace markers for handler authors and the architecture fitness tests; interface inheritance means a type implementing either of them is still discoverable here via reflection's Type.GetInterfaces().

ISender

Single dispatch chokepoint for the CQRS pipeline. Presentation depends only on this interface and on request/response contract types — never on a concrete handler — which is the same decoupling MediatR's IMediator previously provided.

IUnitOfWork

Unit-of-work port over the command database. Lets Application code commit staged changes asynchronously and group multiple operations in an explicit transaction without depending on EF Core.

IUnitOfWorkTransaction

An explicit database transaction started by BeginTransactionAsync(CancellationToken).

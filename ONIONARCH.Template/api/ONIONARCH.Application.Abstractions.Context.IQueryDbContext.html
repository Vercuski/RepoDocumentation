Read-side port for the EF Core persistence path. Defined in Application and implemented by Persistence's QueryDbContext (configured for no-tracking queries).

public interface IQueryDbContext

Remarks

Exposes IQueryable<T> rather than EF Core's DbSet<T> so the Application layer never references EF Core. Because EF Core's async LINQ operators live in EF Core itself, the async materialization methods are surfaced here instead (ToListAsync<TEntity>(IQueryable<TEntity>, CancellationToken), SingleOrDefaultAsync<TEntity>(IQueryable<TEntity>, CancellationToken)).

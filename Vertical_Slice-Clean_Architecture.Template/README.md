# Vertical_Slice-Clean_Architecture.Template

A .NET 10 `dotnet new` template that combines Vertical Slice Architecture with Clean Architecture
layering. Each feature is a self-contained slice: its request, response, validator, handler and
endpoint live together in one file under `Features/`. Domain and persistence concerns stay in their
own projects.

## How a slice works

1. A static class per use case (for example `GetSample`, `PostSample`) nests the slice's
   `Query`/`Command`, `Response`, optional FluentValidation `Validator`, `Handler` and `Endpoint`.
2. `AddSlices` scans the API assembly and registers every `ISliceHandler`, every `IEndpoint`, and every validator.
3. `MapSlices` asks each `IEndpoint` to map its own Minimal API route.
4. `WithValidation<TRequest>()` runs the request's validator before the handler and returns a
   `400` validation problem response on failure.
5. Errors use RFC 9457 `ProblemDetails` responses, built through the `Problems` helpers.
